# cpz

`cpz` is a Zig implementation of the Cap'n Proto wire format. The first milestone focuses on the runtime layer that must be fast, safe, and compatible with the C++ implementation:

- zero-copy readers and allocation-free flat/packed stream message views over caller-owned byte slices and stream buffers, with direct segment/size accessors;
- segmented stream framing compatible with `capnp::serialize`, with bounded segment-count validation and allocation-free segment-table sizing/writing plus allocation-free flat-message serialization into caller buffers;
- C++-style stream prefix sizing via `expectedSizeInWordsFromPrefix` plus segment-count/table/length lookup from serialized prefixes;
- word/pointer/capability encoding with top-level exported low-level pointer types and capability count helpers and byte/word-width and element-kind helper functions, low-level pointer kind/location predicates and decode/asReader/total-size/capability-count inspection, struct/list/far pointer offset/target/shape/payload-byte-size/list-kind predicate helpers, decoded pointer accessor/kind predicate helpers, lazy pointer validation, and schema-agnostic full-message validation/total-size stats with capability index limits and stats/size byte/count and presence helpers;
- arena-backed builders for structs and arbitrary root pointers, with builder option word/byte and predicate helpers for segment sizing, list/text/data/capability root helpers and root pointer introspection/full kind predicates on pointers and message roots/null-checking/clearing and in-progress scalar reads, scalar fields and plus-prefixed/scientific numeric defaults/lists, data-section/pointer-section/shape views with struct-size and shape predicate helpers, pointer lists, UTF-8 text/data blobs with reader defaults, composite struct lists with direct element clearing, generic list element pointer-kind predicates and element/range clearing and per-element/range reader/builder-to-builder copying, schema-evolution bidirectional primitive/pointer list upgrades, list slicing/isEmpty/hasIndex/firstIndex/lastIndex/raw primitive byte views including unaligned primitive reader/builder slices, same-message pointer/root disown/adopt moves with orphan pointer-kind/capability-count predicates with orphanage/orphan allocation/scalar-allocation/copy/scalar-accessors/accessors/release including raw pointer orphan copies, whole-list/struct/pointer/root-pointer deep-copying from readers/builders including bit lists, struct builder-to-builder copying, and explicit pointer clearing;
- packed stream codec compatible with Cap'n Proto packing, including exact packed/unpacked and packed-message size estimation, allocation-free pack/unpack helpers plus reader streaming pack writer and slice/reader streaming unpack writer helpers, packed stream serialization into caller buffers, and packed writer paths that can reuse caller-provided segment-table buffers.
- one-call flat/packed stream framing helpers (`messageToFlatBytes`, `messageToFlatBytesInto`, `writeMessageToWriter`, `messageToPackedBytes`, `messageToPackedBytesInto`, `writePackedMessageToWriter`, `writePackedMessageToWriterWithTableBuffer`, `readMessageFromReader`, `readPackedMessageFromReader`, `readPackedMessage` with trailing-data tolerance) plus owned/view reader constructors with consumed-byte-slice/source-consumed-length/root/default/introspection/serialization convenience methods and builder byte/buffer/writer convenience methods.
- single-segment normalization helper for deterministic flat output (`toSingleSegmentFlatBytes`) and schema-less canonical segment bytes with struct/list truncation (`toCanonicalSegmentBytes`).

The long-term target is to grow into a full schema/compiler/RPC stack while keeping Zig-friendly APIs and predictable performance.

## Build

```sh
zig build test
zig build run
zig build cpzc -- --check schema.capnp
zig build cpzc -- --runtime-import cpz --namespace api --emit-raw-schema-comments schema.capnp generated/generated.zig
```

This repository targets Zig 0.16.0.

## Example

```zig
const cpz = @import("cpz");

var builder = try cpz.MessageBuilder.init(std.heap.page_allocator, .{});
defer builder.deinit();
const root = try builder.initRoot(.{ .data_words = 1, .pointer_count = 1 });
try root.setUInt32(0, 1234, 0);
try root.setText(0, "hello");

const bytes = try cpz.messageToFlatBytes(std.heap.page_allocator, builder.segmentsConst());
defer std.heap.page_allocator.free(bytes);
```

## Scope

The public API is intentionally low-level today. Generated schema accessors can build on top of `StructReader` / `StructBuilder` without changing the wire-format core.
