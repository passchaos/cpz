# cpz

`cpz` is a Zig implementation of the Cap'n Proto wire format. The first milestone focuses on the runtime layer that must be fast, safe, and compatible with the C++ implementation:

- zero-copy readers and flat-message views over caller-owned byte slices;
- segmented stream framing compatible with `capnp::serialize`, with bounded segment-count validation and allocation-free segment-table sizing/writing plus allocation-free flat-message serialization into caller buffers;
- C++-style stream prefix sizing via `expectedSizeInWordsFromPrefix`;
- word/pointer/capability encoding with top-level exported low-level pointer types and helper functions, low-level pointer kind/decode/asReader/total-size inspection, element-size helpers, decoded pointer accessor/kind helpers, lazy pointer validation, and schema-agnostic full-message validation/total-size stats with capability index limits and stats/size count and presence helpers;
- arena-backed builders for structs and arbitrary root pointers with list/text/data/capability root helpers and root pointer introspection/null-checking/clearing and in-progress scalar reads, scalar fields and plus-prefixed/scientific numeric defaults/lists, data-section/pointer-section/shape views with struct-size helpers, pointer lists, UTF-8 text/data blobs with reader defaults, composite struct lists with direct element clearing, generic list element clearing and per-element reader-to-builder copying, schema-evolution bidirectional primitive/pointer list upgrades, list slicing/isEmpty/hasIndex/firstIndex/lastIndex/raw primitive byte views including unaligned primitive reader/builder slices, same-message pointer/root disown/adopt moves with orphanage/orphan allocation/scalar-allocation/copy/scalar-accessors/accessors/release including raw pointer orphan copies, whole-list/struct/pointer/root-pointer deep-copying from readers/builders including bit lists, and explicit pointer clearing;
- packed stream codec compatible with Cap'n Proto packing, including packed/unpacked size estimation, allocation-free pack/unpack helpers, and packed writer paths that can reuse caller-provided segment-table buffers.
- one-call flat/packed stream framing helpers (`messageToFlatBytes`, `messageToFlatBytesInto`, `writeMessageToWriter`, `messageToPackedBytes`, `writePackedMessageToWriter`, `writePackedMessageToWriterWithTableBuffer`, `readMessageFromReader`, `readPackedMessageFromReader`, `readPackedMessage` with trailing-data tolerance) plus owned/view reader constructors with consumed-byte-slice/source-consumed-length/root/default/introspection/serialization convenience methods and builder byte/buffer/writer convenience methods.
- single-segment normalization helper for deterministic flat output (`toSingleSegmentFlatBytes`) and schema-less canonical segment bytes with struct/list truncation (`toCanonicalSegmentBytes`).

## Build

```sh
zig build test
zig build run
zig build cpzc -- --check schema.capnp
zig build cpzc -- --runtime-import cpz --namespace api --emit-raw-schema-comments schema.capnp generated/generated.zig
```

This repository targets Zig 0.16.0.

## Example

```zig
const cpz = @import("cpz");

var builder = try cpz.MessageBuilder.init(std.heap.page_allocator, .{});
defer builder.deinit();
const root = try builder.initRoot(.{ .data_words = 1, .pointer_count = 1 });
try root.setUInt32(0, 1234, 0);
try root.setText(0, "hello");

const bytes = try cpz.messageToFlatBytes(std.heap.page_allocator, builder.segmentsConst());
defer std.heap.page_allocator.free(bytes);
```

## Scope

The public API is intentionally low-level today. Generated schema accessors can build on top of `StructReader` / `StructBuilder` without changing the wire-format core.
